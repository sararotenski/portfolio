Academia das Maravilhas

Com o objetivo de desenvolver um projeto completo e integrado, fui desafiada a criar um sistema para uma academia. Assim nasceu a Academia das Maravilhas, composta por uma página inicial, cadastro e login para alunos e uma página de dashboard onde o aluno pode visualizar e montar seus treinos. Para acessar o site, clique na imagem ao lado!

Habilidades: TESI C1 - H1, H9. IMSI C1 - H3, H5, H8, H10. DESI C1 - H5, H6, H7, H10
