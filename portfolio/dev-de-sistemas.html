Exercícios de Modelo Conceitual

Ao início dessa nova matéria, aprendemos como modelar um banco de dados através dos modelos conceituais. Para fixar o aprendizado, desenvolvi fluxos para três contextos específicos: um sistema de gestão de filmes e séries, um sistema de gerenciamento de escola e um sistema de loja online. O software utilizado foi o brModelo e eu estou gostando muito de aprender mais sobre banco de dados. Para acessar o documento, clique na imagem ao lado!

Habilidades: H1, H2, H3 e H4.
